# 톡차이나 — 무료 브라우저 AI + 신조어 사전

## 작동 방식
- 번역 모델: `Xenova/opus-mt-zh-ko` (Transformers.js)
- 실행 위치: 사용자의 브라우저
- 별도 OpenAI API 키 및 서버 API 비용 불필요
- 자체 신조어 사전: yyds, xswl, 绝绝子, 破防了 등
- 단어장: 브라우저 localStorage 저장
- 반응형: 데스크톱, 태블릿, 스마트폰

## 실행
정적 파일이므로 HTTPS로 배포하면 됩니다. 예: GitHub Pages, Netlify, Vercel.
`index.html`, `style.css`, `app.js`를 같은 디렉터리 구조로 올리세요.
로컬에서 테스트할 때는 간단한 정적 서버를 사용하세요. `file://`로 직접 열면 브라우저 모듈/CORS 정책 때문에 동작하지 않을 수 있습니다.

## 첫 실행 안내
- 최초 번역 시 Hugging Face에서 번역 모델 파일을 다운로드합니다.
- 모델이 브라우저 캐시에 저장될 수 있어 이후 실행은 더 빨라질 수 있습니다.
- 기기·브라우저·메모리·네트워크 상태에 따라 로딩 시간이 길거나 실행이 불가능할 수 있습니다.
- 모바일 저사양 기기에서는 브라우저 AI가 원활하지 않을 수 있습니다.
- 모델 다운로드에는 인터넷 연결이 필요합니다. 다운로드 후 오프라인 사용 가능 여부는 브라우저 캐시 상태에 따라 달라집니다.

## 기능상 한계
- 현재 브라우저 모델은 중국어→한국어 기계번역을 수행합니다. ChatGPT처럼 대화 전체의 의도, 유머, 반어법을 폭넓게 추론하거나 답장을 생성하는 범용 생성형 AI는 아닙니다.
- 자체 사전에서 정확히 등록된 표현을 찾으면 사전 설명을 우선 표시합니다.
- 미등록 신조어는 AI 번역이 어색할 수 있습니다.
- 신조어 사전 데이터는 직접 검수·확장해야 합니다.

## 배포
정적 사이트 호스팅에 폴더 내용을 업로드하면 됩니다. 별도 환경변수/API 키는 필요하지 않습니다.
